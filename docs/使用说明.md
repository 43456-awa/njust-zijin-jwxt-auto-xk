# 教务抢课助手 · 使用说明

## 三步开始

1. 整个文件夹解压到电脑任意位置（**别只拷 exe，model 目录必须一起**）
2. **双击 `xk.exe`**，第一次会问你：学号 → 密码 → **怎么选课（按 1 或 2）** → 间隔 → 模式
3. 之后每次双击就行 —— **验证码自动识别**，不用手输

## 怎么选课（向导里按 1 或 2）

### 按 `1`：指定具体课程
填课程号（`99001731`）或课名（`名画中的瘟疫史`），最多 5 个，按优先级。
**一个都不填也没关系** —— 会自动改成按下面「类别 + 老师」选。

### 按 `2`：按「类别 + 老师」自动选任意一门
先问老师（如填 `紫金慕课`，回车=不限），再问类别：

| 序号 | 类别 |
|---|---|
| 1 | 经济与社会类 |
| 2 | 自然与科学类 |
| 3 | 人文与艺术类 |
| 4 | 创新与技能类 |

输入序号即可（回车 = 不限）。**两个都回车 = 任意一门任选课。**

> 效果：这些课里**任何一门**出现余量就抢那门。实测紫金慕课分布：
> 自然与科学类 17 门、人文与艺术类 15 门、经济与社会类 11 门、创新与技能类 11 门。

## 推荐用法：提前开跑，挂着等

这个工具是给**提前几十分钟开好、一直挂着**用的：

- 选课还没开放 / 页面打不开 / 网络不通 → **不会退出**，会一直等
- 等待时会自动**放慢节奏**（最多 60 秒一轮）并且**不刷屏**，看到这句就说明还活着：

  ```
  ⏳ 列表为空（第 1 轮）：选课可能还没开放，程序会一直等下去，不用管它
  ```

- 一旦列表有数据，会打印 `✅ 列表有数据了，恢复正常速度` 并立刻按你设的间隔（默认 3 秒）开始盯
- 会话失效、网络抖动、提交超时都**自动恢复**
- 只有「密码错误」或你按 `Ctrl+C` 才会停

## 两种运行模式

| 模式 | 行为 |
|---|---|
| **只提醒**（默认） | 有余量只**弹窗 + 响铃**，不替你提交 |
| **自动抢** | 启动输入 `YES`（大小写都行）确认；有余量自动提交，成功后弹窗 |

## 密码输错了怎么办

**不会退出** —— 会当场让你重新输入，并问是否保存到 `config.json`：

```
❌ 教务密码不正确（注意：不是 VPN 密码）
请重新输入教务密码（直接回车 = 退出程序）:
要把新密码保存到 config.json 吗？(y/N):
```

## 高峰期很慢也没关系（内置保底）

| 环节 | 保底做法 |
|---|---|
| 打开页面 / 扫列表 | 12 秒超时，自动重试 3 次 |
| 登录 | 20 秒超时；失败**无限重试**（5 秒起，最长 30 秒一次），不会自己退出 |
| **验证码图片慢** | 25 秒超时 + 3 次重试 |
| 验证码识别 | 本地模型（15–40ms），不依赖网络；识别错自动换一张 |
| **提交超时** | 不当失败 —— 2 秒后回查课表，按课程号精确判定是否真选上 |
| 三个教务节点都慢/不通 | **不放弃**，仍然挑一个硬上，一直重试 |
| 登录态失效 | 自动重新登录 + 自动重选方案 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 「所有节点都没测通，仍选 xxx 硬上」 | 正常（高峰期拥堵），程序会继续重试 |
| 「验证码识别: 手动输入」 | `model` 目录没解压出来 |
| 「符合 N 门，可选 0 门」 | 都满了，正在正常盯着 |
| 「没有符合条件的课」 | 类别/老师名写错，或选课批次还没放量 |
| 想改设置 | 记事本打开 `config.json`；删掉它重新配置 |
| 出问题 | 把同目录的 `xk.log` 发给我 |

## 请务必注意

- **只用自己的账号**
- **别把轮询间隔改到 3 秒以下**
- 用脚本抢课**可能违反校规**，风险自负
